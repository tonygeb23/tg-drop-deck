# Drop Deck 2.4.0, new visible strings

Everything below is new in 2.4.0 and will be seen or spoken.
Nothing ships until you have read it.

To change one, quote its number.

---

## The new Banks menu

Sits between Sounds and Help.

1. The menu itself

    &Banks

2. First item, and its status-bar help

    Re&name this bank...	Ctrl+F2
    Call this bank whatever your board needs it to be called

3. Second item, and its help

    &Reset this bank's name
    Put the shipped name back

## The rename dialog

4. Title

    Rename bank

5. The prompt, with the bank number and its shipped name filled in

    Name for bank 1.

    This changes what the tab is called and nothing else - the keys, the
    looping and the hotkeys all stay exactly as they are. Leave it empty to
    go back to Sound Effects.

6. What it says when you confirm. The tail only appears for banks 3 and 4.

    Bank 1 is now Movie Clips
    Bank 3 is now Under The Show. Still the looping bank
    Bank 4 is now My Keys. Still the bank that takes your own hotkeys

7. Reset, on a bank that was never renamed

    Bank 2 is already called Dialog Drops

Names are capped at 32 characters — long enough for "Sirens and Alarms",
short enough that four of them still fit the tab strip.

## Assigning a folder

8. New item in the Sounds menu, and its help

    Assign a &folder...
    Play a different sound from this folder every press

9. In the right-click menu. The count only appears if it already holds one.

    Assign a &folder...
    Assign a &folder... (now 4 sounds)

10. The folder picker's title

    Choose a folder of sounds for SFX 3

11. What it says once assigned

    Chart Drops assigned to SFX 3. 4 sounds, one at random each press

12. If the folder has nothing playable in it — a message box, not just speech

    Nothing to play

    There are no sounds in that folder.

    C:\Shows\Empty

    It needs at least one wav, mp3, ogg, flac, aiff, aif, w64, au file.

13. On the button itself, and in the search list

    3. Chart Drops, key 3, folder, 4 sounds
    3. Chart Drops, key 3, folder, 1 sound
    3. Chart Drops, key 3, folder, empty

14. When you press it, so you know which one you got

    Chart Drops, down3

15. If the folder was emptied behind your back

    Chart Drops is an empty folder. Put some sounds in it, or assign a file
    instead

16. If the folder itself has gone

    Chart Drops, folder missing. Use File, relink missing sounds

17. In Properties, on the file line

    C:\Shows\Chart Drops   (folder, 4 sounds, one at random each press)

18. Clearing a slot now names what it is clearing

    Clear this folder, Chart Drops, from SFX 3?
    Clear this sound, Applause, from SFX 1?

---

## The Find dialog

19. The instructions at the top, changed. Play no longer closes it.

    Was: Type to narrow the list. Down arrow moves into the results. Enter
    jumps to the sound, Alt+P plays it.

    Now: Type to narrow the list. Down arrow moves into the results. Alt+P
    plays the one you are on and leaves this open, so you can try each
    match. Enter jumps to it and closes.

---

## In the keyboard help (F1)

20. A line above the bank list

    The four bank names below are what the app ships with. Rename any of them
    with Ctrl+F2 — the keys, the looping and the hotkeys are unaffected.

21. Two new sections

    BANK NAMES
      Ctrl+F2                   Rename the bank you are looking at
      Banks menu                Rename, or put the shipped name back
      A name is yours and saves with the board. Renaming bank 3 does not stop
      it being the looping bank, and renaming bank 4 does not stop it taking
      your own hotkeys — those are what the keys do, not what the tab says.

    A FOLDER INSTEAD OF A FILE
      Sounds menu, or right-click a button, then Assign a folder.
      The slot plays a different sound from that folder every time you press
      it, never the same one twice running. Drop another file into the folder
      and it joins in; the app rescans when the folder changes.
      Good for the six jingles that all mean "down the chart".

22. Two lines added under Ctrl+F

      Ctrl+F                    Search every bank by name (Ctrl+E also works)
                                Alt+P in there plays a match without closing
                                it, so you can try each one. Enter jumps and
                                closes.

The startup-announcement fix adds no string. It restores lines the app has
always had and has not managed to say since 2.1.2 — "40 sounds loaded",
"3 files missing. Use File, relink missing sounds", "Audio could not start".
