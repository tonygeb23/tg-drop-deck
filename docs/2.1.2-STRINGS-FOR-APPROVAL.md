# Drop Deck 2.1.2, new visible strings

Everything below is new in 2.1.2 and will be seen or spoken.
Nothing ships until you have read it.

To change one, quote its number.

---

## In the Audio settings dialog

1. Section heading

    Send a bank to its own output

2. The explanation under it

    Leave a bank on the main output unless you want it on a separate
    channel of your mixer. Ducking still works across outputs.

3. The four dropdown labels are just the existing bank names:
   Sound Effects, Dialog Drops, Music Beds, Miscellaneous.

4. What each dropdown is called for the screen reader

    Sound Effects output
    Dialog Drops output
    Music Beds output
    Miscellaneous output

5. The first entry in each dropdown

    Main output

6. The new checkbox

    Say the name when a sound starts or stops

7. Its tooltip

    Turn this off if you can hear the sound and do not need to be told
    about it. Problems, such as a missing file, are always announced.

8. The status line, when more than one output is in use

    Playing through 2 outputs, main is Speakers (Realtek Audio).

---

## Spoken when you close the dialog

9. When nothing is routed away

    Everything playing through Speakers (Realtek Audio)

10. When something is

    Main output Speakers (Realtek Audio). Music Beds through CABLE Input

---

## When a device is missing or in use

11. Spoken, and shown in a message box

    CABLE Input (VB-Audio Virtual Cable) could not be opened, so those
    sounds are going to the default output instead

12. The message box title

    Output not available

---

## Not changed

The existing announcements are untouched. What the new checkbox silences
is only these three, and only when it is off:

    Playing bed, NAME
    Playing bed, NAME looping
    Stopped bed, NAME
    NAME, 0 minutes 4 seconds

These always speak, whatever the setting:

    NAME, file missing. Use File, relink missing sounds
    Could not play NAME
    Everything stopped
    Nothing was playing

The reason for the split is that the first group is confirming something
you can hear, and the second group is telling you something you cannot.
