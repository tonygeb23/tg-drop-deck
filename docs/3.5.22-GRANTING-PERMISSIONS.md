# Granting Drop Deck what it needs, on this Mac, right now

## The quickest way, once 3.5.22 is installed

1. Open TG Drop Deck.
2. **Help menu, "What Drop Deck is allowed to do..."**
3. It reads the three out loud as it opens: Microphone, Camera, Screen
   recording, and whether each is allowed.
4. Arrow to the one you want and press **Return**. macOS asks. Say yes.
5. Or press the **Ask for everything** button, which goes through all three in
   order.

If one says **refused**, macOS will not ask again. Press **Open System
Settings** on that row and it takes you to the right pane with Drop Deck now
in the list.

## Screen recording needs one more step

macOS wants the app quit and opened again after screen recording is switched
on, even though the switch is already set. That is macOS, not Drop Deck. Quit
with Command Q and open it again.

## Why it was not in the list before

An app does not appear under Camera, or under Screen and System Audio
Recording, until it has ASKED. Drop Deck never asked: it only ever read
whether it was allowed, which prompts nobody and registers nothing. So there
was genuinely nothing in the list to find. Fixed in 3.5.22.
