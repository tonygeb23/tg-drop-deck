# Drop Deck for Windows 3.10.1: full review, 24 November 2026

Five reviews, read only, nothing changed in the app: Mark (security), Jessica
(keys, menus, speech), Jackson (audio), Ryder (options, workflow, feedback) and
a wiring check (every menu item, key and setting traced end to end). The
findings marked "confirmed" were re-read in the code afterwards. Windows only;
the Mac was not looked at.

Coverage of the wiring check: 102 menu ids, 25 context menu items, 46
accelerators plus the 80-key digit map, about 63 Preferences controls, 5 other
settings dialogs, all 93 board fields. No two commands share an id and every
key shown in a menu matches what is bound.

## Area 1: Wiring

### Opening a board only half switches (one fix, `dropdeck/ui.py:5029` `_adopt`)

Confirmed. `_adopt` rewires pads, levels and the playlist, and nothing else.
After File Open, New, Load demo, Import or an outside-copy reload:

- The old board's sound cards, monitor card, sources and send keep running
  (`set_bank_devices`, `set_monitor_device`, `apply_sources`, `send_on` are not
  called). Preferences then compares against the board, not the mixer, so OK
  changes nothing. OK in Alt+Shift+S writes the old sources into the new board.
- The old board's global hotkeys stay registered and play whatever sits at that
  slot now; the new board's never register (`_sync_global_hotkeys` only runs at
  startup, `ui.py:990`).
- Folder pads are never scanned, so they say "is an empty folder" until
  Preferences is opened (`warm_cache` is not called). This is feedback 42.
- Bank tab names and counts, hidden pads, the Streaming location tick and the
  saved setups menu stay from the old board (`_refresh_tab_titles`,
  `refresh_visibility`, `_rebuild_station_menu`). A stale setup entry loads by
  position, so it can load a different station.

Fix: finish `_adopt` with those calls. Add a test that opens board B after
board A and checks each one.

### Other wiring defects

- Rename in Source control raises and does nothing, F2 and the button
  (`dialogs.py:4154`). `ask_text` returns a dialog; use the
  `with ask_text(...) as dialog` pattern from `ui.py:3281`. Confirmed.
- Pads and every key are dead while the cue sheet has focus
  (`dialogs.py:6651`): the copied accelerator table raises menu events on the
  dialog and `_forward` is never bound.
- Changing "Put the microphone on air" mid show does nothing until something
  else calls `_sync_air_taps` (`ui.py:7856`). Call it, and
  `apply_source_mixing`, at the end of `_on_settings`.
- Switching microphone in Preferences while it is open can fail silently: the
  mic is closed, "Microphone on" stays ticked, "Preferences saved" is said
  (`ui.py:4295`). Check `start()` as `_toggle_mic` does.
- Preferences can change where Ctrl+B goes, or load a saved station, while live
  (`ui.py:7835`, `dialogs.py:1756`). Use the "come off air first" guard from
  `_on_live_to` and `_on_pick_station`.
- Cancel in Preferences does not fully put back a picked station's screen,
  camera corner, on-screen text and colours, and leaves the station menu stale
  after save or forget (`ui.py:7769`, `dialogs.py:1550`).
- A saved station shares its on-screen text and colours with the board by
  reference, so editing one rewrites the other (`board.py:1445`, `1466`).
  `copy.deepcopy`.
- Picture changes in Preferences while live or recording do not reach the
  picture going out, and nothing says "next time" (`ui.py:7845`).
- Known: the preview_sounds toggle does not `_touch`; a bank 4 pad hotkey can
  take an app key such as Ctrl+S (`_hotkey_map` leaves out `_app_keys()`,
  `ui.py:4416`).
- Buttons disabled while they work push focus to the next control
  (`dialogs.py:5721`, `5536`, `6015`, `6492`, `2817`). Use the existing `_busy`
  flag instead.

Suspected, not confirmed: Ctrl+V in the crossfade box pastes files into the
running order; an autosave that cannot write pops a modal box mid show
(`ui.py:4501`); `_on_player_tick` calls two helpers outside its try
(`ui.py:3443`); `start_sources` on a timer has no try (`ui.py:1017`).

## Area 2: Security

- **A board can load any plugin DLL** (`board.py:1893`, `ui.py:5215`,
  `vst.py:78`). `voice_settings.plugin` goes straight to `load_plugin`, also at
  startup and on a silent reload from a shared folder. Fix: refuse any path not
  in `vst.installed()`. Small. Confirmed.
- **A board can send your stream key to its own server** (`board.py:1803`,
  `1817`). The file's `video_host` is kept even for YouTube and Facebook, the
  key is fetched by station name, and `ask_before_live: false` skips the
  question. Mark's run: the summary said "YouTube Live" while the key went to
  his test host. Fix: for YouTube and Facebook take the host from
  `C.RTMP_INGEST`, never the file; say the host in the summary whenever it is
  not the platform's own. Small to medium.
- **Export and every board carry the Icecast password in plain text**
  (`board.py:1559`, `1599`; export `ui.py:4973`), plus paths holding the
  Windows user name. The guide says the password is in Credential Manager: it
  is not. Fix: blank passwords and fallback keys on export, say "Passwords were
  left out", correct the guide now; later move the password into Credential
  Manager like the vision key.
- **The shot check's Ask box sends the screen without asking**
  (`dialogs.py:5517`, `5680`). If Check the shot never ran, `_last_or_fresh`
  grabs and uploads a fresh screen. Breaks the ask every time rule. Fix: for a
  screen, use only the picture already agreed to, else "Check the shot first".
  Small. Confirmed.
- **Uninstall deletes the whole chosen folder** (`tools/dropdeck.iss:92`,
  `filesandordirs` on `{app}`, folder page not disabled). Installing into
  Documents and uninstalling empties Documents. Fix: `DisableDirPage=yes`, or
  delete only named files. Small. Confirmed.
- A board's `record_folder` can be a network share, and `stream_stats_url` can
  be `file:` or a local network address (`board.py:1862`,
  `streamstats.py:132`). Fix: absolute local folders only, http or https only.
- A board can register machine-wide global hotkeys such as Ctrl+C and Ctrl+V at
  the next start (`globalhotkeys.py:61`). Fix: a global hotkey on a letter
  needs two modifiers.
- Key store slips: `secrets.py:168` `forget` checks without the prefix; a
  vision key Windows refuses to store is dropped without a word
  (`ui.py:7801`).
- **Bigger, own job:** the live RTMPS stream never checks the server
  certificate (`streamout.py:1102`; PyAV passes no options). Someone who can
  redirect DNS on the same network gets the key. Fix is a local relay that
  makes the TLS connection in Python. Medium, needs proving on both platforms.

Checked and fine: signed update manifest with SHA-256 on the download, stream
and vision keys in Credential Manager, feedback sends no paths or names, no key
reaches speech or errors.log, no `shell=True`, export cannot write outside its
folder, per-user installer with no elevation, no secrets in the repo.

## Area 3: Audio

The routing is sound: previews, cue tones and monitoring never reach the
stream, the recorder or the send, and mix minus is exact. The mic chain is safe
at its defaults.

Small fixes:

- A bed started under an open mic jumps in 8 dB loud for the first 50 ms,
  because the duck resets to full whenever nothing is playing
  (`mixer.py:654`). Set it to its current target. Confirmed.
- Previews play out of bank 1's card even when a monitor card is set
  (`mixer.py:1177`). If bank 1 feeds a cable or desk, listeners hear you
  audition. Send previews to the monitor card when one is set.
- Stop everything with the stop fade off clicks (`mixer.py:490`). 5 ms ramp.
- A mic on input 1 of a two-input interface arrives 6 dB down with input 2's
  hiss (`micinput.py:615`, "mix" averages). Take the louder side when the other
  is 15 dB quieter.
- The mic chain keeps its starting sample rate: on a 96 kHz card the 80 Hz high
  pass sits at 160 Hz and the voice goes thin (`micinput.py:386`).
- Nothing stops the send's far end being captured back in, which loops
  (`routing.py:48`). Refuse that setup.

Medium:

- A monitor card at a different rate from the main output plays the monitor
  wrong pitch, with splices (`mixer.py:685`). Resample the monitor feed.
- Mic and source buffers drift with two device clocks: ticks every 20 s or so,
  or the voice creeping 100 ms late over an hour (`micinput.py:224`). Cap the
  fill as the send does (`send.py:292`). Simulated, not measured on hardware.

### The program processor (feedback 47 Jorgen, 49 Alan Young)

This also fixes two measured problems: no headroom before any encoder (MP3,
Opus and AAC peaks above full scale on loud passages; the audio recorder does
not trim although `constants.py:1130` says it does), and the playlist reaching
the stream at full level whatever the presenter's fader says.

- `ProgramChain` in `dsp.py`: a slow leveller, then the existing Ceiling
  limiter. No gate, no EQ in the first version.
- Leveller over 3 s, at most 1 dB a second up and 3 down, boost cap +6 dB, cut
  cap -10 dB, held below -45 dBFS and held while the duck is active.
- Ceiling -2 dBFS, 100 ms release. AAC wants 192 k.
- One instance each in the streamer, the recorder and the send, after the
  cards are summed. Skips the soft clip when on. Never touches the presenter's
  output, so pad latency is unchanged.
- A Preferences page "On air sound" next to Voice: On, "Even out the music"
  (off, gentle, firm), "Never louder than", and a bypass key to compare.
- Loudness matching between songs and pads goes with it: measured four of
  Tony's tracks at -18.0 to -6.5 LUFS, an 11.5 dB jump. Measure once in the
  background pass beside `tail_silence` (`audiofile.py:409`) and use it as a
  default trim, user trim wins.
- Numbers are starting points: record a show through it and measure before
  shipping.

## Area 4: Speech and commands

- Ctrl+M (feedback 48): say "Mic on" and "Mic off". Add the device only when it
  is news (first open, a different device, a fallback), "music ducked" only
  when ducking is on (it is said even with Ctrl+D off), and "not on air" when
  the mic is not reaching the stream (`ui.py:4116`, `4141`).
- Every reconnect repeats the whole going-live line, with a server address.
  First time: "On air" with the station name; after a reconnect: "Back on air"
  (`ui.py:7222`).
- Delete on the playlist track that is on air stops the music with no question
  and, at the middle speech level, no word (`playlistview.py:740`). Ask, for
  that track only. Confirmed.
- Picking "My radio station" in Streaming location says "Ctrl+B now goes to
  your radio station". Since 3.8.2 Ctrl+B is always video and Alt+Shift+B is
  radio (`ui.py:7036`). Say that, and add "For your radio station, press
  Alt+Shift+B" to the stop a radio presenter hears after Ctrl+B
  (`preflight.py:355`). Confirmed.
- The Stop everything button says "Escape three times"; the default is two
  (`ui.py:1558`). Build it from `board.stop_presses`.
- F7 and F8 do not change a recording when "Monitor only" is on; "what you hear
  only" is said only while streaming (`ui.py:2992`). Say it whenever a
  recording or send runs too.
- Alt+Enter on a playlist row says "That one is for the soundboard"; the guide
  says it sets the track's crossfade (`ui.py:3183`).
- Assign a global hotkey says nothing off a pad (`ui.py:2307`). "Move to a
  sound button first".
- Speech landing on a focus move: `announce_answer` and `announce_playback`
  skip the wait `_say` adds after a menu closes; Alt+Shift+W says the whole
  playlist summary as focus moves. Route through `_say`; on a view swap say only
  the view and bank.
- Search says the match count on every keystroke and ignores the speech level
  (`dialogs.py:398`, also `225`, `620`, `3095`, `3381`). Wait 400 ms, honour the
  level.
- Duplicate menu letters: while live, "Come off air" and "Open the recordings
  folder" both F (confirmed); while sending, D twice; playlist row menu T three
  times and R twice (`playlistview.py:609`); bed menu L twice (`ui.py:4441`);
  three dialogs. `tests/test_menus.py` should check the live and sending labels.
- "Microphone on" is a check item: unticked, it may be read as "Microphone on".
  Label it "&Microphone". Needs an NVDA check.

## Decisions for Tony

- System default output: open it through WASAPI shared mode, falling back to
  MME and saying so (Jackson). About 22 ms against about 200. Confirm with a
  cable loopback first.
- Duck while talking (feedback 44): keep "ducks by being open" as the floor and
  add an optional second dip only while the voice is above the gate. Off by
  default.
- Program processor on by default for new boards, off for existing ones.
- Song loudness matching: on or off by default.
- RTMPS certificate relay: its own job.
